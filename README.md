# Dashboard de Performance de Vendas - Desafio Analista

## 📌 Objetivo do Projeto
Este projeto apresenta uma análise visual e interativa de dados de vendas, consolidando informações de clientes, produtos e vendedores em um único Dashboard no Excel. O objetivo é facilitar a tomada de decisão através de KPIs claros.

## 📈 Funcionalidades do Dashboard
- **Filtros Dinâmicos (Segmentação de Dados):** Filtre por data, vendedor ou categoria com um clique.
- **Análise de Faturamento:** Visualização de tendências mensais.
- **Ranking:** Top vendedores e produtos mais rentáveis.
- **Status de Pedidos:** Acompanhamento visual da operação.

## 🛠️ Tecnologias e Ferramentas
- **Microsoft Excel:** Utilização de Tabelas Dinâmicas, Power Query (para limpeza de dados) e Fórmulas Avançadas.
- **Design de Dashboards:** Foco em UX (experiência do usuário) e Storytelling de dados.

## 📂 Conteúdo do Repositório
- `Dashboard_Vendas.xlsx`: Arquivo principal com os dados e painel visual.
- `dados_brutos/`: (Opcional) Pasta com a base utilizada antes do tratamento.
